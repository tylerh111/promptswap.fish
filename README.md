# Promptswap.fish

Promptswap is a simple tool that allows users to swap between different fish shell prompts including built-in and custom prompts.

```bash
fisher install tylerh111/promptswap.fish
promptswap choose  <prompt>      # choose a prompt
promptswap show   [<prompt>...]  # show prompts (default: all)
promptswap list                  # list available prompts
```

Choosing a prompt overwrites `~/.config/fish/functions/fish_prompt.fish` and `~/.config/fish/functions/fish_right_prompt.fish` and reloads the prompt in every running shell.
If either file wasn't generated by `promptswap`, it is first backed up to `<file>.bak`.

## Writing a prompt

A prompt is a function file named `promptswap.<name>.fish` that MUST define `fish_prompt` and/or `fish_right_prompt` (plus any helper functions they need).
If it only defines `fish_right_prompt`, the default `fish_prompt` is used.
If it only defines `fish_prompt`, the right prompt is cleared.

To distribute a prompt with fisher, put it in the `functions` directory of its repository:

```
lambda.fish/
└── functions/
    └── promptswap.lambda.fish
```

```bash
fisher install tylerh111/lambda.fish
promptswap choose lambda
```

Prompts can also be added without fisher by putting the file in `~/.config/fish/functions`.
Installed prompts take precedence over built-in prompts with the same name.
